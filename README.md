## 📋 درباره پروژه

پروژه **Minerva** با هدف هوشمندسازی و یکپارچه‌سازی فرآیندهای درون‌سازمانی طراحی شده است. این سامانه با برقراری ارتباط مستقیم میان بخش **منابع انسانی (HRM)** و **سیستم مالی**، فرآیندهایی مثل ثبت حضور و غیاب پرسنل، مدیریت مرخصی‌ها و محاسبه فیش حقوقی ماهانه کارمندان را کاملاً سیستمی و خودکار پیش می‌برد.

### 🌟 ویژگی‌های برجسته
* 📊 **داشبورد مدیریتی جامع:** نمایش وضعیت کلی سازمان در یک نگاه (دید Top-Down).
* 🔐 **کنترل دسترسی مبتنی بر نقش (RBAC):** پنل‌های مجزا برای مدیر ارشد، مدیر مالی، مدیر HR و کارمندان.
* 💸 **ماشین‌حساب هوشمند فیش حقوقی:** کسر خودکار غیبت‌ها و محاسبه دقیق بیمه، مالیات و اضافه‌کاری.

## 🏗️ ساختار مخزن پروژه (Monorepo)

این پروژه از ساختار تک‌مخزنی (Monorepo) برای مدیریت همزمان فرانت‌اند و بک‌اند استفاده می‌کند:

```text
minerva/
├── backend/       # کدهای سمت سرور (Django REST Framework)
├── frontend/      # کدهای سمت کاربر (React & Next.js)
├── docs/          # مستندات، سناریوها و نمودارهای UML درس نرم‌افزار ۲
└── README.md      # داکیومنت معرفی پروژه (همین فایل)

```
